# Planetary Flow Organ Evidence

Date: 2026-05-29

Fensalir is the right owner for reusable planetary flow only after the problem
is reduced to engine mechanisms: cube-sphere addressing, dataset provenance,
stochastic advection contracts, selected-cut streaming, GPU resources, and
debug evidence. Client repos own planet meaning and consumers.

Useful correction: PlasticAdrift is not a velocity-vector field. It is
transition-matrix style surface transport evidence. The runtime organ should
distill such evidence into mean velocity, covariance/diffusivity, optional
sparse transition logits, and calibrated uncertainty.

Do not train elevation-only flow and call it ocean/atmosphere. Relief is a
static conditioning channel. Dynamic state from ERA5, OSCAR/CMEMS/HYCOM, time
phase, Coriolis/latitude, sea-surface variables, masks, and source quality must
participate before the prediction has authority.
